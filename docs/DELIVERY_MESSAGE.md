デプロイが完了したら、下記の `{APP_URL}` を実際のURLに置き換えて送付してください。

## 送付文面（Web版URL確定後）

```
メル太郎様

お世話になっております、加藤です。
ご期限内にWeb版の準備が整いましたので、ご案内いたします。

■ ご利用URL
{APP_URL}
（ブラウザにこのURLを入力、またはクリックで起動します）

■ ログイン情報（従来と同じキーでそのままご利用いただけます）
・メールアドレス: ＜メル太郎様の既存メール＞
・ライセンスキー: ＜メル太郎様の既存キー＞

■ ご利用手順
1. 上記URLをブラウザ（Chrome/Edge/Safari いずれも可）で開く
2. メールアドレスとライセンスキーを入力して「ログイン」
3. 処理したいPDFをドラッグ&ドロップ（複数同時OK）
4. 「PDFを処理する」ボタンを押す
5. 処理完了後「ダウンロード」ボタンから結果PDFを取得

■ 初回アクセス時のご注意
しばらくアクセスがないとサーバーがスリープ状態になる仕様のため、
久しぶりにご利用の際は起動までに30秒〜1分ほどかかる場合がございます。
画面が真っ白のまましばらくお待ちいただければ自動的に表示されます。

■ ログインについて
ブラウザを閉じる、または長時間放置されますと再度ログインが必要になります。
お手数ですが、ご利用時は毎回ログインをお願いいたします。

■ 従来のexe版との違い
・インストール作業は一切不要（ブラウザを開くだけ）
・Parallels環境の影響を受けません（Web上で動作するため）
・複数PDFを同時にアップロードして一括処理が可能
・ZIPで一括ダウンロードも対応
・追加文言は英数字・日本語どちらも対応

■ 動作確認のお願い
お手隙の際に、実際のラベルPDFで一度お試しいただき、
「新品」の右横に「Made in China」が正しく入っているかご確認ください。
もし不具合がございましたら、お手数ですがスクリーンショット付きでご連絡ください。

今回、exe配布での起動トラブルにより大変ご迷惑をおかけし、
誠に申し訳ございませんでした。Web版への切替のご英断、重ねて御礼申し上げます。

引き続きよろしくお願いいたします。

加藤
```

## 送信前チェック（禁止フレーズ・セルフチェック）

- [ ] 「無料」「サービスで」「追加料金なし」「おまけで」— 含まれていない ✅
- [ ] 「今回は特別に」「ご厚意で」— 含まれていない ✅
- [ ] Web版への切替は元契約範囲内の実装変更として扱う（追加料金を発生させない）
- [ ] 宛名は「メル太郎様」（小池様ではない） ✅
- [ ] ライセンスキーは元のまま流用（新規発行なし = クライアント負担なし）

## Web版URLの埋め込み前の確認事項

Streamlit Cloud でデプロイが成功し、以下の動作確認が済んでから送付：

1. [ ] URLにアクセスできる（HTTP 200）
2. [ ] メル太郎様の実キーでログイン成功
3. [ ] サンプルPDF（または手持ちPDF）で処理実行できる
4. [ ] 結果PDFに「Made in China」が正しく挿入されている
5. [ ] 複数PDF同時アップロード → ZIP一括ダウンロードが動く
